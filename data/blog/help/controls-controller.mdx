## What input devices work?

House House officially supports mouse and keyboard and most computer game controllers. Nintendo Switch 2 mouse mode is also supported. Every action can be rebound from **Settings → Rebinding**.

## Fast controller checklist

1. Confirm the controller produces input in the operating system or a controller test page.
2. Fully close Big Walk, reconnect the controller and reopen the game.
3. Disconnect extra gamepads, steering wheels or unusual USB input devices.
4. In Steam, enable Steam Input and use the default Big Walk profile.
5. Rebind the affected action in-game instead of assuming the default layout is active.

## Xbox controller on Mac

The official FAQ records reports involving Xbox Wireless Controllers with Steam on macOS. Connect by Bluetooth, create a controller profile for Steam under macOS Game Controllers, enable **Increase Compatibility**, allow Steam under Accessibility and Input Monitoring, and enable Steam Input.

## Accessibility-related controls

Big Walk offers hold/toggle choices, multiple crosshair styles and full rebinding. If a challenge requires an input you cannot perform, the host can enable challenge skipping when starting the session.

## Diagnose the symptom before changing profiles

| Symptom                                    | Most useful first check                               |
| ------------------------------------------ | ----------------------------------------------------- |
| No buttons respond                         | Test whether the operating system sees the controller |
| Two actions fire at once                   | Disable one remapping layer or duplicate device       |
| Movement works but interact does not       | Restore defaults, then rebind that action             |
| Controller works outside Steam only        | Enable Steam Input with the default profile           |
| Mac Xbox controller behaves inconsistently | Use Bluetooth and the macOS compatibility steps above |

After a fix, test grab, point, kick and communication inputs—not only movement—before returning to a puzzle.
