## The useful answer

Reconnect the controller before launching, close conflicting remapping software, choose a supported layout and test default bindings before rebinding.

## Step by step

1. Power-cycle or reconnect the controller.
2. Close duplicate input and remapper apps.
3. Launch Big Walk and restore defaults.
4. Rebind one action at a time.

## Why players get stuck here

Steam Input or two simultaneous controller layers can produce duplicate or missing actions.

## Separate hardware failure from game configuration

Test the controller outside Big Walk first. If the operating system cannot see an input, repair the cable, Bluetooth pairing or battery before changing Steam settings. If the test works, disconnect other input devices and allow only one remapping layer.

On macOS with an Xbox Wireless Controller, the official FAQ recommends Bluetooth, a Steam-specific controller profile with Increase Compatibility, Steam accessibility/input-monitoring permissions and the default Steam Input profile.

## Verify it before moving on

Change one variable at a time, then retest from a fresh session. That makes it clear which fix worked and avoids turning a connection, audio or input problem into several overlapping problems.
