## Who owns the save?

The **host** keeps the shared world and its progress. Guests contribute while connected, but they cannot independently reopen that same journey later. Pick a host who can attend future sessions before the group invests hours in a world.

## Does the game autosave?

Yes. The official FAQ says host progress is saved automatically. You do not need a manual save command before leaving.

## How to continue next session

1. The original host opens Big Walk and loads the continuing world.
2. Wait until the host character has entered the world.
3. Guests join from the friends list or use the newly generated Join Code.
4. Confirm that completed towers and returned rewards match the previous session before moving on.

## What if the host leaves?

The session closes and all guests disconnect. Another player cannot take over the save mid-session. If the host only needs a short break, avoid ending the session unnecessarily.

## Can a different player become host?

Official documentation does not describe save transfer or cross-progression between hosts. Assume the original host is required unless House House adds a supported migration feature later.
