## Fast checklist

1. Copy the Join Code again and remove spaces before or after it.
2. Confirm the host is still inside the session that generated the code.
3. Make sure every player is running the same game version.
4. Check that crossplay is enabled when platforms differ.
5. Have the host recreate the session and send a fresh code.
6. Restart the game and network connection if a fresh lobby also fails.

## Remember who owns progress

The host stores the group progress. If you recreate a continuing session, the same person should host it so the group returns to the correct save.

## Before reporting the issue

Note the host platform, joining platform, error text, time and whether a new code changed anything. This makes a support report much more useful.
