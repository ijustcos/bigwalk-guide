- **You can hear nearby friends but they become quiet at distance:** proximity voice is working as designed.
- **Nobody ever hears you:** check input device, permissions and mute state.
- **Every player is unusually quiet at close range:** update the game; launch-week tuning improved quiet microphone setups.

## PC checklist

1. Confirm the correct microphone is the operating system's default input.
2. Allow desktop apps to use the microphone in privacy settings.
3. Close software that takes exclusive control of the input.
4. Reconnect the device, restart Big Walk and rejoin the session.
5. Test at close range before treating distance attenuation as a fault.

## PS5 checklist

1. Check the controller mute light.
2. Select the correct input under Sound → Microphone.
3. Adjust the microphone level and confirm the meter moves.
4. Leave console party chat when testing in-game proximity voice.
5. Restart the game after changing permissions or input devices.

## Still broken?

Record the platform, headset model and whether the input meter moves. Then check current official patch notes before reinstalling the game.
