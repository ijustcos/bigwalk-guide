## The useful answer

Set the PC or console date, time and timezone to automatic, then restart Big Walk. An incorrect system clock can prevent secure session connections.

## Step by step

1. Open system date and time settings.
2. Enable automatic time and timezone.
3. Synchronize now.
4. Restart the game and retry the live code.

## Why players get stuck here

This is easy to miss on Switch 2 or a console that has been offline because every other network setting can look correct.

## Why an incorrect clock blocks multiplayer

Online session security depends on timestamps. A device can browse the web normally yet reject hosting and joining when its clock is far from online time. Enable automatic date, time and timezone, force a synchronization and perform a full restart.

If every player has accurate time but only one still fails, move on to version matching and network checks; do not keep regenerating codes as the only test.

## Verify it before moving on

Change one variable at a time, then retest from a fresh session. That makes it clear which fix worked and avoids turning a connection, audio or input problem into several overlapping problems.
