## The useful answer

Switch 2 can join PC, Mac and PS5 sessions through crossplay. A wrong console date/time is a known cause of connection failure.

## Step by step

1. Enable crossplay.
2. Synchronize the Switch 2 clock automatically.
3. Enter the host’s live join code.
4. Restart after version updates.

## Why players get stuck here

A correct code can still fail when system time is wrong or one platform has not installed the current patch.

## Distinguish a code problem from a platform problem

First test a newly generated code after the host is visibly in the world. If the code works for PC or PS5 but not Switch 2, synchronize the console clock, restart rather than sleep the console and compare the first two game-version numbers. The third version number may differ.

Mouse mode support on Switch 2 is an input feature; it does not change the crossplay or save rules.

## Verify it before moving on

Before inviting everyone, agree on the host, world size, voice or text preference and the next session time. Those four details prevent most groups from losing progress or creating a world they cannot continue.
