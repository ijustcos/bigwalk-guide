## Why there are too many buttons

Big Walk configures some cooperative puzzles around the number of players selected when the host creates the session. The setting can be wrong even when the correct number of people actually joined.

<GameImage
  src="/static/images/big-walk/official-04.jpg"
  alt="Big Walk players cooperating around an island structure"
  caption="Some challenges change with the world size chosen by the host, so count the active buttons before assuming the room is broken. Official screenshot."
/>

<Spoiler label="Reveal the fix">
  Open **Session Details** and check the player setting. If it does not match your group, back out,
  let the host choose the correct number of players, and restart the session. It is not too late to
  change it.
</Spoiler>

## Will you lose your items?

Hold the items you want to keep before restarting. They should appear at the starting area's Lost and Found when the corrected session begins.

## How to confirm the fix

Return to the room with the corrected session size and count the simultaneous positions again. The number of required players should now match the world variant. If it does not, confirm the host actually recreated the session instead of reopening the old one.
