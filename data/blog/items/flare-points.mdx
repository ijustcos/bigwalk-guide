## The useful answer

Find it at the tutorial exit, Map Room and the tops of towers. Its main use is to launch a fixed-location signal visible from far away.

## Step by step

1. Go to the item location: at the tutorial exit, Map Room and the tops of towers.
2. Make sure one player has a free hand, back slot or hip slot before picking it up.
3. Use it to launch a fixed-location signal visible from far away.
4. Return it to a memorable landmark if your group does not want to carry it.

## Why players get stuck here

Tools are physical objects in Big Walk: they can be dropped, moved, worn or left behind between destinations. Tell lost players which flare station you are using because multiple red flares can be visible. A useful item is only useful if the rest of the group knows who is carrying it.

## Quick checklist

- Confirm the item visually before leaving the area
- Choose one named carrier
- Tell the group where it will be returned
- Tell lost players which flare station you are using because multiple red flares can be visible.

## Verify it before moving on

Test the item near the place where you found it, then note whether it changes with distance, sound, light or another player. Many tools are communication aids rather than keys that directly unlock one door.
