## Does crossplay work between every supported version?

Yes. Use a Join Code when friends are on different platforms. Same-platform friend lists are only a convenience; they do not create a different type of world.

The Mac App Store edition does not support Game Center friend discovery, so those players should use a Join Code even when joining another Mac player.

## Is progress shared between platforms?

The official FAQ describes progress as belonging to the host save. It does not promise cross-platform save transfer or cross-progression. Crossplay means playing together, not moving a host world between accounts or systems.

## Which version should your group buy?

Choose any currently supported system that each player can use reliably; the puzzle content and online group are not separated by platform. A mixed PC, Mac, PS5 and Switch 2 party should plan to join by code and keep crossplay enabled.

Do not buy an Xbox or original Switch copy expecting it to appear later: House House currently says no other platforms are planned. If that changes, the official FAQ and store pages should be treated as the source of truth rather than an old launch article.
